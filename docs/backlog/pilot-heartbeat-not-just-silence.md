# pilot-heartbeat-not-just-silence

Пилот видит тишину (last_seen), но не видит «работаю, просто долго»:
агент 20 мин пишет код без tool-вызовов — для пилота он мёртв,
для дела он жив. Отсюда ложные ALARM и nudge в момент глубокой работы.

Сделать: heartbeat от агентов — любой pair_*-вызов (даже pair_state)
уже обновляет last_seen, но молчаливая работа без вызовов не видна.
Добавить лёгкий pair_ping (только last_seen, без побочек), CLI шлют
его каждые N мин сами. Пилот различает «молчит, но пингует» (работает)
и «молчит и не пингует» (встал).
