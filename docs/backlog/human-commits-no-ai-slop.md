# human-commits-no-ai-slop

Симптом: коммиты, PR-описания, notes, комменты в коде — ИИ-слоп:
«feat(pair): ...» пачками без связи, простыни в verdict.md, дубли
одного и того же разными словами, эмодзи, «comprehensive», «robust».

Правило (в протокол, §10 рядом с «ветка на задачу»):
1. Коммит = одна мысль: заголовок ≤72 символов, глагол в повелительном
   («убери», а не «убрано/убирает»); тело — ПОЧЕМУ, а не ЧТО (что видно
   в диффе). Нет «почему» — не коммить, допиши сначала.
2. Запрещённые слова в сообщениях: comprehensive, robust, leverage,
   seamless, cutting-edge, delve, tapestry, «в современном мире».
   Список пополняемый, лежит в этом файле.
3. Notes: одна запись = один факт/решение/вердикт. Простыня >30 строк —
   режь на plan/finding/decision отдельно. Дубли одной мысли разными
   словами — удаляй, оставляй точную.
4. Комменты в коде: только «почему так, а не иначе» + ссылка на
   измерение/карточку. Пересказ кода словами запрещён.
5. Критик проверяет сообщения как часть ревью: слоп в коммите =
   обоснованное возражение, как за код.
