## Где

`install.sh:108-117` (`write_instructions`), esp. `:113`

## Что сломается

```python
if MARK in text:
    path.write_text(text.split(MARK)[0].rstrip() + "\n" + MARK + NOTE, encoding="utf-8")
```

`split(MARK)[0]` — всё, что человек написал **после** маркера `<!-- pair-mailbox -->`,
удаляется без предупреждения и без резервной копии. Для профиля `opencode` это
`~/.config/opencode/AGENTS.md`, файл пользователя; для `claude` — `~/.claude/CLAUDE.md`,
тоже пользовательский.

Файл переписывается на каждом запуске установщика, так что потеря происходит
повторно и молча. PROTOCOL §12 требует останавливаться при удалении истории;
здесь обрезание чужого файла проходит без вопроса.

## Почему отложили

Раунд был в режиме `audit` (`bin/pairctl mode audit`): работа раунда — evidence, а не diff, поэтому правка кода в нём не делалась. Находка подтверждена соседом и ждёт отдельного раунда `fix`.

## Что сделать

1. Заменить `text.split(MARK)[0]` на разбор по позициям маркера с сохранением хвоста,
   либо на `str.replace(MARK + <старое тело>, MARK + новое)`.
2. Писать `.bak` перед перезаписью пользовательского файла.
3. Сообщать, сколько символов хвоста затёрто.
