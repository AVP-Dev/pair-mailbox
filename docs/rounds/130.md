# Round 130 — the backlog rule gets a gate, and the directory gets back to the shape the protocol describes

- **Mode**: fix · **Autonomy**: auto · **Branch**: `round-130-backlog-gate`
- **Writer**: omp · **Critic**: agy (independent drafts `.pair/notes/plan-round130-omp-draft.md` and `.pair/notes/plan-round130-agy-draft.md`; agreed plan `.pair/notes/plan-round130-agreed.md`)

## What was wrong

The rule "this directory holds open debt only" is written in three places, and
nothing checked it:

- `docs/PROTOCOL.md:551` — "fixed cards are deleted from `docs/backlog/` with
  the fix recorded in the commit message — history keeps the record, the
  directory keeps only open debt"
- `docs/PROTOCOL.ru.md:531` — the same, in Russian
- `skills/pair-backlog/SKILL.md:36` — the same, in the skill an agent follows
  when it files a card

`grep` over `scripts/*.sh`, `scripts/*.py` and `mcp/pair_mailbox/*.py` for
`docs/backlog` returns four mentions, all of them prose inside other code
(`review.py:7`, `server.py:1266,1369,1807`). Not one check.

So the directory did not hold open debt only. It held **five cards with
`status: fixed`** — `protocol-layer-silent-pass.md` (closed in round 123),
`same-cli-duo-instance.md` (closed in round 124), and three closed in round
129 — plus **two cards whose frontmatter was incomplete**:
`merge-path-and-branch-base.md` had no frontmatter at all, and
`permission-ask-hook-per-cli.md` had no `round` and no `status`. A reader
browsing the folder on GitHub saw a list of open debts that was not one.

Three of the five closed cards were closed by **this writer, in round 129,
one round ago** — the round whose merged card is the precedent for the fix
(`docs/rounds/129.md`). The rule was broken by the same hand that proposed to
enforce it, which is why the enforcement could not be optional.

## What was done

**The rule became a check.** `scripts/backlog-check.py` reads every card in
`docs/backlog/`, and refuses: a missing field, an empty field, an extra field,
a `status` that is not `open`, a `severity` outside low/medium/high/critical, a
`round` that is not a positive integer, a `found` that is not a date, a file
that is not markdown, a file with no frontmatter, a missing directory. It names
the file and the field, and it never repairs anything — a gate that edits the
tree is a gate nobody can trust about what it found.

**The gate is wired into the gate.** `scripts/verification-profile.tsv` gains
one static row:

```
backlog-lint	static	1	python3 scripts/backlog_check_test.py && python3 scripts/backlog-check.py
```

Both halves matter, and the second one is not a copy of the first. The test
file proves the checker works (18 tests over real card files in a temporary
tree); the command that follows applies it to **this repository's** directory.
The nearest precedent, `scripts/branch_class_check_test.py`, runs only against
temporary repositories — it never checks the real one, so a broken branch name
in this repo would pass it. That is the same class of hole this repository has
now fixed three times: a check whose green claims more than it checked.

**The directory was put back.** The five closed cards are deleted, and the
commit that deletes them says what closed each one. The two malformed cards
were repaired. `merge-path-and-branch-base.md` held two unrelated defects with
different severities, so it became two cards: `merge-escaped-the-audit-trail.md`
(high) and `branch-base-is-unwritten.md` (medium).

**The numbers for the two repaired cards were reconstructed, not invented.**
`permission-ask-hook-per-cli.md` was filed by the merge of PR #7
(`feff7e1`, 2026-10-05T07:07:05Z); the critic's verdict on that PR says
"permission.ask ... Откладываем в бэклог"
(`.pair/notes/archive/verdict-20261007T095627+0000.md:16`), and the plan of
round 11 is the §7 rewrite about the bounded `pair_read`
(`.pair/notes/archive/decision-20261018T183000+0000.md:32-33`) — exactly the
content of PR #7. So the round is 11. The two new cards were added by the same
commit that added `docs/rounds/115.md`, so their round is 115.

**Nothing is stored that can go stale.** `docs/backlog/README.md` says what
the directory is and names two commands; it has no lists and no counters, so it
cannot disagree with the directory. The open debt and the closed archive are
printed on demand:

```
$ python3 scripts/backlog-check.py --index
backlog-check: 13 open card(s) in docs/backlog/
  critical    0
  high        1  merge-escaped-the-audit-trail.md
  medium      9  branch-base-is-unwritten.md, pair-state-costs-...
  low         3  composer-line-none-idle-pane.md, ...
  rounds with open debt: 11, 104, 106, 110, 113, 115, 126, 127, 129
  rounds with open debt and no round card in docs/rounds/: 11, 104, 106, 110, 113, 126

$ python3 scripts/backlog-check.py --closed
backlog-check: 53 closed card(s) in git history
```

The archive is git, because the protocol says git keeps the record. A second
directory of closed cards would be a second source of truth about debt that is
already closed — the same mistake as a committed index, only smaller.

## What was measured

| what | before | after |
|---|---|---|
| problems the rule-check finds in the tree | 23, across 7 files | 0, across 13 cards |
| cards with `status: fixed` in the directory | 5 | 0 |
| cards with incomplete frontmatter | 2 | 0 |
| checks that read `docs/backlog/` | 0 | 1, in the static layer |
| static layer after a `status: fixed` card appears | green | red, naming the file |

Red-proofs, run against the tree this round changed:

- the gate over the old tree: 23 problems, naming every file and every field;
- a probe card with `status: fixed` in the directory: the static layer goes
  red — `backlog-lint: failed (exit 1, required)` — and names the file; remove
  the probe and the layer is green again;
- 18 tests over real card files, each of them failing before the fix that
  made it pass: a closed card, a missing field, an empty field, an extra
  field, a file with no frontmatter, an unknown severity, a round that is not
  a number, a round of zero, a `found` that is not a date, a file that is not
  markdown, a missing directory (exit 2, not a pass), the README exemption,
  and the archive read out of git.

Two of the tests failed on the first run and named real defects in the first
draft of the checker: `--closed` demanded that the live directory still exist,
although the archive lives in git and outlives the file; and the index skipped
the round gap when `docs/rounds/` was absent, which is the case where the gap
is largest. Both are fixed, and both have a test.

## What stays open

Thirteen cards, all `status: open`, listed by `--index`. The round that filed
open debt and has no round card in `docs/rounds/` is reported by the same
command: rounds 11, 104, 106, 110, 113 and 126. That is a different gap from
this one — the round cards' history — and it is not this round's business.

## What a reader should take away

A rule in a document is not a rule. This one sat in three places for months,
and the directory it governs drifted away from it while every document kept
repeating it. The fix is not another paragraph: it is a check that fails, in
the layer that runs on every change, naming the file that broke the rule — and
a directory that is now exactly what the protocol has always said it is.
